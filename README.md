# la-le-na Shopify theme

Dedicated Shopify Online Store 2.0 theme for **la-le-na**.

## Local development

1. Install the Shopify CLI.
2. Sign in to the Shopify account that has access to `ra-le-na.myshopify.com`.
3. From this repository, run `shopify theme dev --environment development`.
4. Before sharing changes, run `shopify theme check`.

Store domains, theme IDs, access tokens, and other credentials must not be committed to this repository.

The committed development environment identifies only the target store. It does not contain a password, access token, or live theme ID.

## Project isolation

This theme is independent from every other project. Do not reuse another store's configuration, content, assets, identifiers, or credentials without explicit approval.
