# la-le-na project instructions

This repository is the dedicated Shopify theme for **la-le-na**.

The designated development store is **ra-le-na.myshopify.com**.

- Never copy settings, credentials, store domains, theme IDs, brand assets, copy, or implementation details from another project unless the user explicitly supplies and approves them for la-le-na.
- Treat this repository as an independent project even when another project has a similar name.
- Keep Shopify credentials and store-specific values out of Git. Use Shopify CLI authentication or untracked local environment files.
- Preserve Shopify Online Store 2.0 conventions and keep merchant-editable content in section or theme settings where practical.
- Run Shopify Theme Check before delivery when the tool is available.
- Do not publish, push, or modify a live Shopify theme unless the user explicitly asks.
